## Partir d’un modèle

<!-- ecran: /modeles -->

L’écran **Modèles** présente des objets tout prêts, entièrement réglables. Tapez quelques lettres
dans **Rechercher un modèle** pour filtrer la liste, puis touchez une carte : le modèle s’ouvre dans
l’[éditeur](#léditeur).
